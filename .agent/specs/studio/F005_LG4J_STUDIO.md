# F005 add jsdoc with type definition

## Instructions

Add jsdoc to file studio/webui/src/lg4j-graph.js with type definition (to be compatible to typescript).
Take a look as example to studio/webui/src/lg4j-graph-mermaid.js
Take in consideration that the jsdoc should be compatible with typescript and should include type definitions for all functions, parameters, and return values.
Ensure that the jsdoc comments are clear and concise, providing useful information for developers who will be using or maintaining the code.
During the process if you infer new complex type put their definition in source studio/webui/src/types.js and import them in the files where they are used.
