# F003 Visualize the graph DSL

## Description

We need to visualize the graph DSL in a web application. The preferred tech. stack is:

### Frontend
    * [React 19](https://react.dev/reference/react)
    * [React Flow](https://reactflow.dev/api-reference)
### Backend
    * [Spring Boot](https://spring.io/projects/spring-boot)

## Implementation

The web application must be a Single Page Application (SPA) which the first page must allow to load a DSL (JSON).
Once DSL loaded it must visualize as a visual graph relying on React Flow component.
The spring boot application must publish an end point that return the JSON generated by a Langgraph4j graph instance

Such application must be generated in `langgraph4j-core/src/test/java` under the package `org.bsc.langgraph4j.dsl`


## Implementation summary

Implemented a test-scope Spring Boot SPA in `langgraph4j-core/src/test/java/org/bsc/langgraph4j/dsl` with `LangGraphDslVisualizerApplication`. The application serves a React 19 and React Flow based single-page UI at `/`, allowing users to fetch the sample DSL from `/api/graph`, paste custom Langgraph4j DSL JSON, and render it as an interactive graph. The `/api/graph` endpoint generates JSON from a real Langgraph4j graph instance with a nested subgraph via `CompiledGraph.toJSON()`. Added Spring Boot test dependencies to `langgraph4j-core`, resolved the module's test logging and Jackson version conflicts, and covered both SPA and DSL API endpoints with `LangGraphDslVisualizerApplicationTest`.
