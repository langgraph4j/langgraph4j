## Reporting a Vulnerability

Please report security vulnerabilities by creating an issue in this repository. 
If the vulnerability is critical, you can use the GitHub Security Advisory feature (if enabled) to privately report it to the maintainers, or email the project owner directly.

We will try to review all vulnerabilities within 48 hours and provide an update on a timeline for a patch.
